App Store screenshots from "Vocabulary" (word-learning app), saved as visual
reference for Social Pulse's own design pass — not for reuse verbatim, just
to study the palette, card layout, and copy tone.

- `vocab-design1.png` — onboarding/marketing screens (vocabulary card, streak
  timer, quiz flow, category picker)
- `vocab-design2.png` — widgets, custom word entry, streak calendar, wallpaper
  lock-screen tie-in, ranking/score screen
